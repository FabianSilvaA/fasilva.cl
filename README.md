# fasilva.cl — sitio personal de Fabián Silva-Aravena

Primera versión estática preparada para GitHub Pages.

## Estructura

- `index.html`: contenido principal.
- `assets/css/style.css`: diseño y responsive.
- `assets/js/main.js`: menú móvil y año automático.

## Cómo editar

### Cambiar textos
Editar directamente `index.html`.

### Agregar una publicación
Buscar la sección `publication-list` y duplicar uno de los bloques de publicación.

### Agregar un proyecto
Duplicar una tarjeta dentro de la sección `#proyectos`.

## Publicar en GitHub Pages

1. Crear un repositorio público, por ejemplo `fasilva.cl`.
2. Subir todos estos archivos a la raíz del repositorio.
3. En GitHub: Settings → Pages.
4. En “Build and deployment”, seleccionar “Deploy from a branch”.
5. Elegir `main` y `/root`.
6. Guardar.
7. Probar primero la URL que entregue GitHub Pages.
8. Luego configurar el dominio personalizado `fasilva.cl`.

## Importante

No se incluyó el CV descargable porque el archivo actual contiene datos personales que no conviene publicar en abierto.
Cuando exista una versión pública del CV, puede añadirse y enlazarse desde la sección Perfil.
