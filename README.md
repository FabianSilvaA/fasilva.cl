# fasilva.cl — Version 6

Actualización integral del sitio académico y profesional.

## Cambios principales
- Actividad científica y editorial con filtros por año.
- Congresos, comités, chair, revisión por pares, Guest Editor y otras actividades académicas ampliadas.
- Publicaciones consolidadas, sin duplicados y organizadas por año.
- Nombres de revistas sin incluir el nombre de la editorial (por ejemplo, “Cancers”, no “Cancers, MDPI”).
- Tesis separadas en Magíster, Pregrado y Doctorado.
- Docencia ampliada con el historial de asignaturas de pregrado y postgrado.
- Reconocimientos y premios incorporados.
- Se eliminaron referencias a “sin horas APA” y columnas administrativas de horas/jefaturas/observaciones.
- Se mantiene la sección de prensa y difusión de la versión 5.

Sitio estático preparado para GitHub Pages.
